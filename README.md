# 📊 TeoChart Bot FREE

AI-powered technical analysis for **MetaTrader 4 / MetaTrader 5** chart screenshots.
Upload a chart → get Bias, Entry, Stop Loss, Take Profit, Risk:Reward, Confidence and a short reason.

**100% free stack.** No paid APIs, no paid database, no credit card. Analysis runs on the free tier of **Google Gemini 1.5 Flash**.

---

## Features

- Drag & drop or click-to-browse upload (PNG / JPG / JPEG, max 10MB)
- Client-side image compression before upload
- Smart Money Concepts (SMC) prompt: BOS, CHOCH, FVG, supply/demand, structure, trend
- Colored bias badges — BUY (green), SELL (red), WAIT (yellow)
- Confidence progress bar
- Copy Trade Plan to clipboard + Clear Results
- Last 10 analyses stored locally in the browser (no database)
- Friendly error handling: bad file type, oversized file, missing API key, Gemini errors, rate limits, invalid JSON, network failures
- Responsive dark trading dashboard

## API

### `POST /api/analyze`

`multipart/form-data` with field `chart` (PNG/JPG/JPEG, ≤10MB).
The image is held in memory only for the duration of the request — nothing is written to disk.

Response:

```json
{
  "pair_timeframe": "EURUSD H1",
  "bias": "BUY",
  "pattern": "Bullish engulfing",
  "market_structure": "Higher highs / higher lows",
  "trend": "Bullish",
  "key_level": "1.0850 demand",
  "entry": "1.0862",
  "sl": "1.0834",
  "tp": "1.0930",
  "rr": "1:2.4",
  "confidence": 72,
  "reason": "BOS above prior high with retest of demand."
}
```

Errors return `{ "error": "message" }` with an appropriate HTTP status
(400 invalid upload, 413 too large, 415 wrong type, 401 bad key, 429 rate limit, 502 Gemini/JSON failure).

### History

The last 10 analyses are stored in the browser under the `teochart_history_v1` localStorage key.
The app runs on a serverless runtime with no writable disk, so browser storage replaces `server/history/data.json` — still no database, still free. Clicking a history card reloads that analysis.

## Gemini setup notes

- Package: `@google/generative-ai`
- Model: `gemini-1.5-flash` (free tier)
- The key is read server-side only (`process.env.GEMINI_API_KEY`) inside the request handler and never shipped to the client.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| "Missing Gemini API key" | Add `GEMINI_API_KEY` to `.env` (or project secrets) and restart the dev server. |
| "Gemini rejected the API key" | Regenerate the key at Google AI Studio; make sure there are no spaces. |
| "Gemini free-tier rate limit reached" | Free tier is limited per minute — wait ~60 seconds and retry. |
| "The AI returned an unreadable response" | Retry; use a clearer, less cluttered chart screenshot. |
| "File too large" | Max 10MB — take a smaller screenshot or crop it. |
| Bad or generic analysis | Include the symbol and timeframe in the screenshot and keep price action visible. |
